
# Игра "Крестики-нолики"

Учебный проект на Python с использованием библиотеки Tkinter. Игра представляет собой классическую игру "Крестики-нолики" для двух игроков.

## Особенности:
- Возможность настроить количество побед, до которых нужно играть (по умолчанию 3).
- Игра заканчивается, когда один из игроков набирает заданное количество побед.
- Поддержка сброса игры и подсчета побед.

## Запуск игры:
1. Убедитесь, что у вас установлен Python.
2. Запустите файл с кодом, и откроется графический интерфейс игры.
